# Sebastian Prusky Portfolio

A static, gallery-clean personal portfolio for art and technical projects.

## Structure

- `app/page.tsx`: portfolio content, section structure, placeholder art, and project data
- `app/globals.css`: visual system, responsive layout, and section styling
- `app/layout.tsx`: metadata, fonts, and document shell

## Local Development

```bash
npm install
npm run dev
npm run build
```

## Content Updates

The best time to add final content is after the layout direction feels right.
Replace the placeholder arrays in `app/page.tsx` with real artwork titles,
image paths, project descriptions, and contact links.

For Lovable, connect the finished GitHub repository and use Lovable for visual
polish once the content model is stable.
